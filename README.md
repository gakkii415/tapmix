# 自動ミックスDJアプリ

初心者向けに操作を絞った、ブラウザだけで動くDJアプリです。2曲を選び、再生を押すと、音量と切り替えを自動で調整します。

- 音源の準備なしで試せるオリジナルのインスト音源を2組収録。
- ボカロ・EDMの有名曲を5組、公式YouTubeリンク付きで提案。
- 手元の音源を追加すると、ブラウザ内で保存・解析して自動ミックス。
- 一時停止・再開・停止・音量の操作に対応。

YouTubeの試聴は、公式プレーヤー1つでの連続再生です。音声を抽出したり、2曲を重ねたりする機能はありません。有名曲の自動ミックスには、ご自身で利用できる音源を追加してください。おすすめへの掲載は加工許諾を意味しません。

## 動作

各曲の冒頭から最大約32秒ずつを使い、数秒重ねて約1分のミックスを作ります。テンポを十分な確かさで推定でき、差が小さい場合は拍を合わせます。速度調整に伴って音の高さも変わります。それ以外は元の速度でクロスフェードします。

追加した音源は現在の配信元・ブラウザのIndexedDBに保存され、サーバーへは送信しません。別の配信元や端末への引き継ぎはありません。削除はアプリ内の音源管理画面で行えます。

## ローカルで開く

ビルドやAPIキーは不要です。ES modulesを使うため、HTMLを直接開かずHTTPで配信します。

```sh
python3 -m http.server 8080
```

`http://localhost:8080/` をブラウザで開いてください。

## 検証と公開

```sh
npm run check
npm test
```

作業前の完全なコミットSHAを控え、反映前に `AGENTS.md` に従って `.github/mandatory.py` の修正・再検査を実行します。正式バージョンは `index.html` の専用領域に表示します。

GitHub Pagesは `main` ブランチ直下を配信します。フォントはGoogle Fonts、試聴は同意後にYouTubeから読み込みます。ブラウザの自動再生設定、広告、地域・埋め込み制限により試聴が止まる場合は、公式リンクから開けます。
