# ワンタップ音楽ミックスプレーヤー

公開済みのマッシュアップやDJセットを選び、ワンタップで聴くブラウザアプリです。制作者が仕上げた1本の動画をYouTubeの公式プレーヤーで再生するため、音源の追加や曲ごとの操作は不要です。

- Zedd「Clarity × Stay The Night」— DJ Love制作。
- Avicii「Wake Me Up × The Nights」— FriedMixes制作。
- Porter Robinson「Secret Sky Set (2020)」— 本人公開のDJセット全編。「Tell Your World」などを含み、最初から再生します。

各候補に制作者名と元動画へのリンクを表示します。アプリがYouTubeの原曲2本から新しくミックスを作る機能ではありません。動画の公開情報・収録曲から選んだ候補であり、音質・つなぎの試聴評価や現在の埋め込み再生可否は確認できていません。

初回の再生操作でYouTubeの読み込みに同意します。ブラウザの設定によっては動画内の再生ボタンを押す必要があります。広告・地域制限・埋め込み制限がある場合は、元動画へのリンクから開けます。閉じた動画は破棄し、別タブへ移ったときは一時停止します。

## 手元の音源で遊ぶ

オリジナルのインスト音源2組と、ローカル音源で短いミックスを作る機能もあります。各曲の冒頭から最大約32秒ずつを使い、数秒重ねて約1分のクロスフェードを作ります。テンポを十分な確かさで推定でき、差が小さい場合は拍を合わせます。速度調整に伴って音の高さも変わります。それ以外は元の速度でつなぎます。曲の構成・フレーズ・キーによる最適なつなぎの判定は行いません。

追加した音源は現在の配信元・ブラウザのIndexedDBに保存され、サーバーへは送信しません。別の配信元や端末への引き継ぎはありません。削除はアプリ内の音源管理画面で行えます。

音源で遊ぶ候補のYouTube試聴は、2つの公式プレーヤーを同じ画面に並べる方式です。各動画内の再生ボタンで個別に開始し、アプリから両方を一時停止できます。この機能は公開済みミックスの再生と別の機能です。

## ローカルで開く

ビルドやAPIキーは不要です。ES modulesを使うため、HTMLを直接開かずHTTPで配信します。

```sh
python3 -m http.server 8080
```

`http://localhost:8080/` をブラウザで開いてください。

## 検証と公開

```sh
npm run check
npm test
```

作業前の完全なコミットSHAを控え、反映前に `AGENTS.md` に従って `.github/mandatory.py` の修正・再検査を実行します。正式バージョンは `index.html` の専用領域に表示します。

GitHub Pagesは `main` ブランチ直下を配信します。フォントはGoogle Fonts、動画は再生操作・同意後にYouTubeから読み込みます。
